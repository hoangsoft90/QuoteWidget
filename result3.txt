BONUS FIX: ID GENERATION FLAKY TEST
================================================================================

Vấn đề:
  _generateId() trong cả 3 model (Collection, Item, WidgetConfig) dùng
  DateTime.now() trong vòng lặp List.generate(12, ...) → 12 giá trị
  giống hệt nhau trong cùng 1 microsecond → 2 entity tạo nhanh có
  thể có cùng ID → Hive overwrite item cũ bằng item mới → test flaky.

Fix:
  Thay thế bằng microsecondsSinceEpoch + atomic counter:
    static int _idCounter = 0;
    static String _generateId() {
      final ts = DateTime.now().microsecondsSinceEpoch.toRadixString(36);
      final seq = (_idCounter++).toRadixString(36);
      return '$ts-$seq';
    }
